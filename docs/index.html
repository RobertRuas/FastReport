FastReport
Código Descarregar

Fotos no sítio certo. Relatório depois.

FastReport é uma aplicação nativa para Mac que organiza fotos de inspeção e de trabalho diretamente no Finder. Não guarda uma biblioteca. Não escreve o relatório. Prepara pastas, nomes e ordem para o relatório futuro ser rápido.

Descarregar para Mac macOS 14 ou posterior · Apple Silicon e Intel

O disco é a verdade

As fotos ficam nas pastas do projeto. A app move, converte para JPEG 1024 e renomeia. Nada de nuvem nem coleção escondida.

Teclado primeiro

Triagem uma a uma: T1 a T24 com o buffer numérico, General com 0, lixo com ⌘⌫, desfazer com ⌘Z.

Mapas, não código rígido

O mapa de inspeção T24 define pastas e atalhos. Outros tipos de trabalho entram como dados, sem reescrever a app.

Português e inglês

A interface muda de idioma nas Definições. Os nomes das pastas no Finder mantêm-se estáveis.

Atualizações na app

Definições avisa quando há versão nova. A instalação só começa quando confirmas. Progresso real da descarga.

Feito para o dia de campo

Importação em lote, revisão por pasta e sincronização se alguém mexer no Finder enquanto trabalhas.

Como instalar

O FastReport não está na App Store. É uma aplicação de terceiros. O macOS pode bloquear a primeira abertura — isso é normal.

  1. Descarrega o zip e abre-o com um duplo clique.
  2. Arrasta FastReport para a pasta Aplicações. Não a deixes em Descargas.
  3. Abre a app a partir de Aplicações.
  4. Se o sistema recusar: Definições do Sistema → Privacidade e segurança, desce até Segurança e clica Abrir mesmo assim. Confirma Abrir.
  5. Em alternativa: no Finder, botão direito em FastReport (em Aplicações) → Abrir → Abrir.

Como se usa

Crias um projeto no sítio que escolheres. Importas as fotos do cartão. Classificas. Abres o Finder: T10 já tem Projeto_T10_1.jpeg. O relatório, noutro momento, lê essa estrutura.
